# AI-Disclosure Flags

Caller sets these per-post. The skill does not default them on. This is by design (Adithya's explicit choice) so callers think about each post. Read the warnings below carefully.

## The fields

| Platform | Field in `platformSpecificData` | What "true" means |
|----------|----------------------------------|-------------------|
| YouTube | `containsSyntheticMedia` | Video contains realistic altered or AI-generated content. |
| TikTok | `video_made_with_ai` | AIGC label displayed on the video. |
| Instagram | (none exposed via Zernio) | Meta auto-detects via C2PA; manual label only available in the app, not the Graph API. |

## Why default-off is risky

Platform policy as of 2026-04:

- **YouTube**: Creators MUST disclose realistic AI content. Non-disclosure plus auto-detection equals a Community Guidelines strike (not a warning). 2025 Q3 enforcement wave removed channels with billions of cumulative views under the "Inauthentic Content" policy. If an agent generated any part of the video, default-off equals default-risk.
- **TikTok**: Integrated C2PA detection in Jan 2025. If the file was made by Sora, Runway, Kling, or similar, TikTok auto-detects the metadata. If the AIGC label is NOT set but the metadata is present, TikTok treats this as intentional non-disclosure and issues an immediate strike.
- **Instagram**: Meta's own auto-detection flags AI content but through the app UI only. Zernio does not expose a pre-set flag. If posting AI-generated content to IG, consider manually adding the AI label via the app after the skill finishes.

## Rule of thumb for callers

Set flags true if ANY of the following is true for the post:

- The media was generated by a generative-video model (Sora, Runway, Kling, Veo, etc.).
- The audio was TTS-generated or voice-cloned.
- A realistic human likeness was altered (face swap, deepfake, lip-sync).
- AI was used to generate photorealistic still images.

Set flags false only if:

- Media is entirely camera-captured real footage.
- Edits are limited to non-AI tools (cuts, color grading, captions).
- No C2PA metadata is present in the file.

Do not set flags false "because the video looks good enough to pass." The platforms are not asking about visual quality, they are asking about provenance. C2PA detection catches metadata even when human eyes can't tell.

## What the skill does

- Skill prints the current flag values at the confirmation gate.
- Skill does not alter values the caller set.
- Skill does not default to true for "safer" behavior, because false negatives (claiming human when AI) are the TOS risk and defaults would mask caller intent.
- If the file was uploaded via `zernio.sh upload` and the skill can detect C2PA metadata locally (future enhancement), it will warn at the gate.

## If caller is unsure

Treat unsure as true. Disclosure of human content as AI is not a TOS violation. Disclosure of AI content as human is.
