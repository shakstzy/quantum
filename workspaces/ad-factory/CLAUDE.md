# ad-factory

Self-improving AI UGC ad pipeline. Per-product: research what's winning in the niche, write a script, render via Higgsfield, edit, ship, learn.

## Purpose

Adithya runs his own ecom products. Each product gets a UGC ad generated by an AI host pulled from a persistent host library (one host per niche, persona + look + voice + real social handle tracked durably). Pipeline: scrape top 50 IG/TikTok videos in the niche, Gemma analyzes, Claude synthesizes angle patterns, picks the host, writes a script, drives Higgsfield Marketing Studio (UGC preset) to render, ffmpeg cuts hero + 9x16 + 1x1, ships via zernio-post, scrapes own metrics at 24h/7d/30d, writes learnings back to `shared/learnings/`. Each new run reads recent learnings to bias toward winning patterns.

## Hard Rules

1. **One niche per host.** Cross-niche reuse only on neutral products (kitchen, home).
2. **Scraped mp4s are ephemeral.** After Gemma writes `stages/01-research/output/<product-slug>-research.md`, the raw mp4s in `~/.quantum/ad-factory/scrape-tmp/` are deleted.
3. **Hosts have real social handles.** Each host's `persona.md` tracks the IG/TikTok handle they post from. Never ship the same product twice from the same host.
4. **Learnings are durable, mp4s are not.** `shared/learnings/*.md` is the only thing that persists across runs.
5. **Render only after script approval.** Stage 02 emits 3 variants. Operator picks one. Stage 03 does not fire until pick.
6. **Ship gate is mandatory.** Literal `PUBLISH` token required before zernio-post fires (Pattern 11).
7. **Topic-bound seeding.** Hosts are seeded only when a real topic is being run, never speculatively. The `_template/` folder ships empty.
